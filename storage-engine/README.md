# storage-engine

Файловая база данных приёмов ветклиники на Go с интерфейсом на Fyne (лабораторная работа №2). Поиск, добавление и удаление по ключу — O(1) благодаря хеш-индексу на диске; поиск по виду и врачу — O(1 + k) через двусвязные цепочки внутри записей.

Подробное описание, форматы файлов, анализ сложности и замеры — в [отчёте](../docs/lab2/report.md).

## Запуск

```bash
go run ./cmd/seed -out ~/vetcare-demo   # демо-база на 300 приёмов
go run ./cmd/vetdb                      # приложение: Файл → Открыть базу… → ~/vetcare-demo
go test ./...                           # тесты
go run ./cmd/bench                      # замеры на 1k–1M записей → bench.csv
```

Демо-база — 300 приёмов за последние два месяца и следующие две недели: 8 видов животных, 8 врачей, все статусы. Размер задаётся флагом `-n`, одинаковый `-seed` даёт одинаковые данные.

На macOS нужны Go 1.24+ и Xcode Command Line Tools (`xcode-select --install`); на Linux — пакеты для Fyne (`libgl1-mesa-dev xorg-dev libxkbcommon-dev libwayland-dev`).

## Устройство

| Пакет | Что делает |
| --- | --- |
| `internal/record` | модель приёма, запись фиксированной длины 198 байт, валидация |
| `internal/hashfile` | хеш-таблица на диске: открытая адресация, tombstone, rehash |
| `internal/heap` | файл записей `visits.dat` со списком свободных слотов |
| `internal/db` | фасад: CRUD, вторичные индексы, поиск и удаление по полю, резервные копии |
| `internal/export` | выгрузка в .xlsx |
| `internal/ui` | интерфейс на Fyne |
| `cmd/vetdb` | точка входа приложения |
| `cmd/bench` | замеры производительности |
| `cmd/seed` | демо-база с реалистичными приёмами |

База — папка из четырёх файлов: `visits.dat`, `key.idx`, `species.idx`, `doctor.idx`.

| Операция | Сложность |
| --- | --- |
| Добавление, поиск, удаление, редактирование по ID | O(1) в среднем |
| Поиск и удаление по виду или врачу | O(1 + k) |
| Поиск по кличке или статусу | O(n), полный проход |
