# Генератор данных клиники

Создаёт синтетические данные ветклиники VetCare за два года (01.11.2024–31.10.2026) по схеме `dwh/01_schema.sql`: по CSV-файлу на каждую таблицу в `data/raw/`. Одинаковый `SEED` даёт одинаковые данные, поэтому CSV не коммитятся — их всегда можно пересоздать.

| Таблица | Строк |
| --- | ---: |
| branches | 3 |
| doctors | 14 |
| owners | 4 500 |
| pets, medical_cards | ~6 200 |
| visits | ~28 000 |
| payments | ~23 000 |
| vaccinations | ~4 800 |

## Заложенные закономерности

Все «истинные» параметры лежат в `config.py`. Аналитика на шагах с метриками и A/B-анализом должна их найти.

- **Сезонность.** Весной и летом приёмов больше, зимой меньше (`MONTH_WEIGHTS`); прививок в марте–мае вдвое больше. В воскресенье приёмов меньше, вечером больше.
- **Неявки** (`no_show`) растут в понедельник, в слоты до 10:30 и с каждым днём между записью и приёмом.
- **A/B-эксперимент.** С 01.03.2026 случайной половине записей (кроме записей в тот же день) отправляется SMS-напоминание; оно снижает вероятность неявки на 30% (`REMINDER_EFFECT`).
- **Лояльность и отток.** У каждого владельца скрытая лояльность: лояльные ходят чаще и дольше не уходят. Новые клиенты приходят на первый приём в течение двух недель после регистрации — по ним строятся когорты.
- **Врачи.** Владелец ходит в «свой» филиал; врач нанят до даты приёма; хирургия — только у хирургов. У каждого врача свой множитель цены, поэтому средние чеки различаются.
- **Цены** зависят от типа приёма и размера животного; постоянным клиентам иногда скидка 10%, остальным — акция 5%.
- **Связность.** Оплата только у состоявшихся приёмов, по одной; прививка — результат состоявшегося приёма типа `vaccination`; приёмы после 31.10.2026 — запланированные.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python generate.py      # CSV в data/raw/, около 10 секунд
pytest                  # тесты: правила схемы и наличие закономерностей
ruff check . && ruff format --check .   # линтер и форматирование
```
